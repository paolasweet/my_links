# sweet-pao-links

Linkseite von Pao, gehostet auf Netlify (automatisches Deployment aus diesem Repository).

- `index.html` – die komplette Seite inkl. 18+-Bestaetigung (keine externen Abhaengigkeiten)
- `netlify.toml` – Netlify-Einstellungen und Sicherheits-Header
- Optional: ein Profilbild als `avatar.jpg` (quadratisch, ca. 400x400 px) in diesen Ordner legen; es ersetzt automatisch das "P".

Wichtig: Der Pinterest-Code `p:domain_verify` im `<head>` von `index.html` muss bei jeder Aenderung erhalten bleiben.
