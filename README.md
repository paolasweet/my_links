# Sweet Pao - Linkseite

Wird automatisch von Netlify veroeffentlicht.

Dateien:
- `index.html` - die Seite inkl. 18+-Bestaetigung
- `netlify.toml` - Netlify-Einstellungen und Sicherheits-Header

Bilder einfach in dieselbe Ebene wie index.html hochladen, die Seite nutzt sie automatisch:
- `hero.jpg` - grosses Titelbild (Hochformat 4:5, z. B. 1080x1350 px). Nur ein Bild ohne Nacktheit verwenden.
- `fansly.png`, `fanvue.png`, `mym.png` - quadratische Logos (z. B. 256x256 px). Fehlt eine Datei, erscheint ein Buchstabe.

Wichtig: Der Pinterest-Code `p:domain_verify` im `<head>` von `index.html` muss erhalten bleiben.
